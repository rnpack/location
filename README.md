# @rnpack/location

Location permissions and adapter state

## Installation


```sh
npm install @rnpack/location react-native-nitro-modules

> `react-native-nitro-modules` is required as this library relies on [Nitro Modules](https://nitro.margelo.com/).
```

## Required dependencies

```sh
yarn add @react-native-community/geolocation react-native-permissions react-native-system-setting react-native-design @react-native-async-storage/async-storage moti react-native-autocomplete-dropdown react-native-gesture-handler react-native-svg react-native-vector-icons react-native-reanimated react-native-worklets @rnpack/utils buffer
```


## Usage


```js
import { multiply } from '@rnpack/location';

// ...

const result = multiply(3, 7);
```
